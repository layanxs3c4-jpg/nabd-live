# NABD Live — ابدأ من هنا

هذه نسخة مطوّرة من AIRI ومهيأة لاستقبال أحداث TikTok LIVE عن طريق TikFinity.
اسم برنامج Windows هو **NABD Live**، وله بيانات وإعدادات منفصلة عن AIRI الرسمي.

## الوظائف الموجودة

- قراءة التعليقات والهدايا والمتابعات والاشتراكات والمشاركات والإعجابات.
- إرسال الحدث إلى AIRI لترد الشخصية بالصوت والحركة وفق إعداداتها الحالية.
- عدم عرض حالة **Verified** إلا بعد استقبال حدث بث حقيقي.
- تسجيل عدد الرسائل الخام والأحداث المعروفة وغير المعروفة لتشخيص الاتصال.
- حفظ نقاط المتابعين وعرض أفضل عشرة متابعين.
- أوامر الدردشة `!نقاط` و`!ترتيب`، مع دعم `!points` و`!top`.
- مسابقة سؤال واحد: أول إجابة صحيحة تربح النقاط.
- تصويت جمهور: كل متابع يصوت مرة واحدة برقم الخيار أو اسمه.

## بناء ملف Windows من GitHub

يتضمن المشروع المسار الآلي `.github/workflows/nabd-windows.yml`.
هذا المسار يبني محرك الشخصية وملف تثبيت Windows على جهاز Windows سحابي.

1. ارفع مصدر المشروع إلى مستودع GitHub خاص بك.
2. افتح تبويب **Actions**.
3. اختر **Build NABD Live for Windows**.
4. اضغط **Run workflow**.
5. بعد نجاح البناء، نزّل الملف **NABD-Live-Windows-x64** من قسم Artifacts.
6. فك الضغط، ثم شغّل ملف `NABD-Live-0.11.3-windows-x64-setup.exe`.

ملف الاختبار غير موقع بشهادة تجارية. قد يعرض Windows تحذير SmartScreen باسم
**Unknown publisher**. التوقيع الرسمي يحتاج شهادة توقيع برامج مستقلة.

## اختبار TikFinity على بث حقيقي

1. افتح TikFinity على نفس جهاز Windows الذي يشغّل البث.
2. شغّل بث TikTok LIVE وانتظر حتى يتصل TikFinity بالحساب.
3. افتح NABD Live، ثم افتح **Settings → TikFinity LIVE**.
4. الصق عنوان WebSocket الذي تعرضه صفحة TikFinity LIVE API. العنوان الشائع هو
   `ws://localhost:21213`.
5. اضغط **Connect**.
6. حالة **Socket open** تعني أن المنفذ مفتوح فقط. اكتب تعليقًا حقيقيًا في البث.
7. عندما يستقبل NABD التعليق، تتغير الحالة إلى **Verified by a live event** ويظهر
   التعليق في سجل الأحداث الخام والمعروفة.

إذا بقيت الحالة **Socket open** بعد التعليق، انسخ أحدث Raw frame من الصفحة. هذه
البيانات تكشف صيغة الحدث التي أرسلها إصدار TikFinity الموجود على جهازك.

## تشغيل المسابقات والتصويت

- اكتب السؤال والإجابات المقبولة وقيمة الجائزة، ثم اضغط **Start and announce**.
- يعلن NABD السؤال بالصوت من خلال الشخصية، وينهيه عند أول إجابة مطابقة.
- اكتب سؤال التصويت وخيارين أو أكثر، ثم اضغط **Start and announce**.
- يصوت المتابع بكتابة `1` أو `2` أو اسم الخيار. اضغط **Finish and announce result**
  لإعلان النتيجة.

## إعداد الصوت والشخصية

تكامل TikFinity يرسل الأحداث إلى قناة AIRI الداخلية. لذلك يستخدم الرد نفس نموذج
اللغة والصوت والشخصية اللذين تختارهما داخل إعدادات NABD Live. يجب إعداد مزود نموذج
المحادثة ومزود الصوت قبل اختبار الرد الصوتي.
